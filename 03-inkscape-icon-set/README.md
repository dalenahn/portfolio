# Inkscape — icon set

20 stroke-based icons on a 24px grid. All 2px stroke, rounded caps and joins, no fills.

`icon-sheet.svg` is the contact sheet. `icons/` has individual SVGs.

| Category | Icons |
|---|---|
| Playback | play, pause, stop, skip-forward, skip-back |
| Nav | home, search, chevron-left, chevron-right |
| User | user, chat, mail, phone |
| Status | check, close, plus, minus |
| Theme | sun, moon, star, heart |
| Files | download, upload |
| System | settings |
