# Portfolio

A few small projects across the 2D/3D toolchain.

## Projects

### Godot 4 — top-down sandbox
A minimal top-down 2D scene built for quick agent/RL experiments. Player, walls, goal, step counter. Open `01-godot-ai-playground/project.godot` in Godot 4.2+ and press F5.

### Blender — synthetic dataset generator
A single Python script that renders YOLO-labeled images of randomized 3D primitives. Headless, seed-reproducible.

```
blender --background --python 02-blender-synthetic-data/generate_dataset.py -- --count 500
```

### Inkscape — icon set
20 stroke-based icons on a 24px grid. Browse `03-inkscape-icon-set/icon-sheet.svg` for the full sheet, or grab individual files from `icons/`.

## Tools
GIMP, Inkscape, Krita, Libresprite, Blender, Godot, Python
